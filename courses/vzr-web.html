HTML, CSS, JS (продвинутый) + React

Уровень: Уровень: Профессиональный Объём: Объём: 120–160 ак.ч Цена: Цена: 40 000–80 000 ₽

Полный курс веб-разработки: от верстки до SPA на React. Работа с Git, API, фреймворками.

Программа

  • Модуль 1. HTML5/CSS3, адаптив, БЭМ (20 ч)
  • Модуль 2. JavaScript ES6+, асинхронность, DOM (30 ч)
  • Модуль 3. Git, npm, Webpack (20 ч)
  • Модуль 4. React (компоненты, состояние, роутинг) (40 ч)
  • Модуль 5. Проект – SPA (остальное время)

Результат

Готовое SPA-приложение в портфолио.

Требования

  • Базовое знание HTML/CSS/JS
  • Компьютер с установленным VS Code
