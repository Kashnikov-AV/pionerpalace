Знакомство с анализом данных на Python: Pandas, визуализация, простые модели машинного обучения.

## Программа

- Модуль 1. Python для анализа (8 ч)
- Модуль 2. Pandas и очистка данных (12 ч)
- Модуль 3. Визуализация (Matplotlib/Seaborn) (10 ч)
- Модуль 4. Введение в ML (Scikit-learn) (10 ч)
- Модуль 5. Проект – анализ датасета (8 ч)

## Результат

Умение анализировать данные и строить графики.

## Требования

- Базовый Python
- Компьютер с Jupyter или VS Code
