Изучение Python через создание игр (Pygame), телеграм-ботов, парсинг данных и основы искусственного интеллекта.

## Программа

- Модуль 1. Основы Python (10 ч)
- Модуль 2. Игры на Pygame (14 ч)
- Модуль 3. Телеграм-боты (12 ч)
- Модуль 4. Парсинг и работа с API (10 ч)
- Модуль 5. Введение в AI (10 ч)

## Результат

Создание собственной игры и чат-бота.

## Требования

- Компьютер с интернетом
- Установленный Python и Pygame
