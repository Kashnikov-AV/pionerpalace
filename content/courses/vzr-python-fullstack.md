Полный курс веб-разработки на Python: от основ языка до создания полноценных веб-приложений с использованием Django/Flask, REST API, баз данных и деплоя.

## Программа

- Модуль 1. Основы Python (синтаксис, типы данных, функции, ООП) – 20 ч
- Модуль 2. Работа с базами данных (SQL, ORM) – 16 ч
- Модуль 3. Веб-фреймворки: Django/Flask – 30 ч
- Модуль 4. REST API, аутентификация, безопасность – 16 ч
- Модуль 5. Фронтенд (HTML, CSS, JS) – 18 ч
- Модуль 6. Деплой, Docker, Git – 10 ч
- Модуль 7. Итоговый проект – 10 ч

## Результат

Вы сможете создавать веб-приложения любой сложности, работать в команде и разворачивать проекты на серверах.

## Требования

- Базовое знание Python (переменные, циклы, функции)
- Компьютер с установленным Python и VS Code
