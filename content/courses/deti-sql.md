Знакомство с реляционными базами данных, языком SQL на примерах из игр и соцсетей.

## Программа

- Модуль 1. Что такое БД (6 ч)
- Модуль 2. SELECT, WHERE, JOIN (12 ч)
- Модуль 3. Группировка и агрегация (8 ч)
- Модуль 4. Проектирование и проект (10 ч)

## Результат

Создание своей БД для проекта (например, библиотека игр).

## Требования

- Компьютер с интернетом
- Доступ к онлайн-среде SQL
